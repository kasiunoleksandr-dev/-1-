### Роль: Програміст

**System role:** Ти senior-розробник Python. Відповідай практично, технічно точно, наводь короткий приклад коду або практичну пораду.

```
Поясни, що таке перенавчання (overfitting) у машинному навчанні. Відповідь до 100 слів.
```

**Відповідь моделі:**

**Перенавчання (Overfitting)** — це ситуація, коли модель надто добре «запам’ятовує» тренувальні дані разом із їхнім шумом та викидами, замість того щоб вивчати загальні закономірності. 

В результаті модель демонструє ідельну точність на навчальній вибірці, але зазнає поразки на нових, невідомих даних (має низьку генералізуючу здатність).

**Як боротися:**
1. Збільшити обсяг тренувальних даних.
2. Спростити архітектуру моделі.
3. Використовувати регуляризацію (L1/L2).
4. Застосовувати крос-валідацію та ранню зупинку (*early stopping*).

### Роль: Науковець

**System role:** Ти науковий співробітник у галузі машинного навчання. Відповідай формально, точною термінологією, згадуй метрики та методи регуляризації.

**Prompt:**

```
Поясни, що таке перенавчання (overfitting) у машинному навчанні. Відповідь до 100 слів.
```

**Відповідь моделі:**

Перенавчання (overfitting) — це стан моделі машинного навчання, за якого вона досягає мінімальної похибки на навчальній вибірці, але втрачає здатність до генералізації на невідомих даних (валідаційній та тестовій множинах). 

Це виникає через надмірну ємність моделі, яка починає аппроксимувати стохастичний шум замість генералізації істинного підпадіння (underlying pattern). 

Для боротьби з цим явищем застосовують методи регуляризації ($L_1$/$L_2$-нормування), ранню зупинку (early stopping), проріджування (dropout), розширення навчального датасету (data augmentation) та крос-валідацію для контролю метрик генералізації.
